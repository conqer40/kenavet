## 🚀 الخيار 2: منصة Render.com (الخيار الأفضل والمجاني 100%)
منصة **Render** هي البديل الأقوى لـ Vercel/Netlify، وتتميز بأنها تدعم تشغيل خوادم Node.js حقيقية (Full Server) وليست Serverless فقط، مما يجعلها مثالية لتطبيقات الـ CRM وقواعد البيانات.

### المزايا:
1. **خطة مجانية كاملة (Free Web Service Tier):** 750 ساعة عمل مجانية شهرياً.
2. **رابط HTTPS رسمي ومجاني:** مثل `kenavet-crm.onrender.com`.
3. جاهزة تماماً في مجلد المشروع، حيث قمنا بإنشاء ملف الإعدادات الجاهز `render.yaml`.

### خطوات الرفع (خلال 3 دقائق):
1. قم بإنشاء حساب مجاني على [Render.com](https://render.com).
2. ارفع مجلد المشروع على حسابك في GitHub (مستودع خاص أو عام).
3. في لوحة تحكم Render، اضغط **New +** ثم اختر **Web Service**.
4. اختر المستودع الخاص بك من GitHub، وستجد الإعدادات مجهزة تلقائياً:
   * **Environment:** `Node`
   * **Build Command:** `npm install && npm run build`
   * **Start Command:** `npm run db:migrate && npm run db:seed && npm start`
   * **Environment Variables:** أضف المتغير:
     * `ALLOW_LOCAL_DB` = `true`
     * `NODE_ENV` = `production`
5. اضغط **Create Web Service**، وخلال دقيقتين ستحصل على رابط رسمي دائم ومجاني ترسله للعميل.

## 🚂 الخيار 3: منصة Railway.app
منصة ممتازة جداً وسريعة في مصر والشرق الأوسط:
1. افتح [Railway.app](https://railway.app) وسجل بالـ GitHub.
2. اضغط **New Project** -> **Deploy from GitHub repo**.
3. تكتشف المنصة تطبيق Next.js والـ Dockerfile تلقائياً وتبدأ بالبناء.
4. تمنحك رصيداً تجريبياً مجانياً شهرياً ورابط HTTPS مباشر مثل `kenavet.up.railway.app`.

---

## ☁️ الخيار 4: منصة Koyeb.com
منصة سحابية متقدمة توفر حاويات مجانية (Free Nano Service):
1. افتح [Koyeb.com](https://www.koyeb.com) وسجل مجاناً.
2. اختر **Deploy via GitHub** أو **Dockerfile** (الملف مجهز في المشروع).
3. ستحصل على رابط عالمي سريع مجاني ينتهي بـ `.koyeb.app`.
